A complete story in exactly six words: **"The letter arrived after the funeral."**

A letter arrives — but its reader is already gone. Who wrote it, what it said, and why it came too late are left for the reader to fill in. The program is deterministic: it writes that one fixed line to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

It creates `/output` if needed and writes the six-word story to `/output/entry.txt`.
